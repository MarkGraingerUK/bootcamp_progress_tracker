# Bootcamp Quiz Results Dashboard

A professional, interactive Power BI portfolio project tracking quiz performance, subject mastery, and progression throughout the Data Technicians Skills Bootcamp.

## 📊 Project Overview

This dashboard was built to monitor, analyze, and visualize daily quiz results and academic progress. It transforms raw tracking data into actionable insights, providing both high-level KPIs and granular row-level data exploration.

## 🛠️ Key Features

* **Interactive Slicers:** Filter the entire dashboard dynamically by week to analyze performance trends over time.
* **KPI Summary Cards:** Instant visibility into overall metrics, including total quizzes taken, cumulative questions answered, and overall average percentage correct.
* **Visual Breakdown:** Charts displaying performance distribution across subjects and modules.
* **Detailed Summary Log:** A clean, formatted table at the base of the canvas displaying date, subject, title, question counts, correct answers, and percentage correct per quiz.

## 🗂️ Files Included

* `bootcamp_progress_tracker.pbix` — The complete Power BI dashboard file.
* `Bootcamp_Quiz_Results.xlsx` — The underlying source dataset.

## 🚀 How to View

1. Download the `.pbix` file from this repository.
2. Open the file using **Power BI Desktop**.
3. Explore the interactive slicers and visuals!
